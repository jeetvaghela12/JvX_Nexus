# Versions below are MINIMUM floors (>=), not exact pins, and were checked
# against PyPI as of July 2026 (search results, not training-data recall --

# cryptography, passlib -- their floors below are reasonable but less
# rigorously checked, and it's genuinely possible newer minors exist by the
# time this is installed.

# `pip freeze > requirements.lock.txt` (or use pip-tools / uv / poetry) to
# capture exact resolved versions for reproducible builds. Minimum-version
# constraints are the right choice for a template like this one -- they
# won't fail to install over an exact-pin guess that's since gone stale --
# but they are NOT a substitute for a real lockfile before this goes into
# the stress test or production.

# --- Database ---
sqlalchemy>=2.0.51
